# Travel App Customer & Booking Analytics

## 📌 About
This project analyzes customer and booking data from a travel application to understand customer behavior, travel preferences, bookings, and revenue.

## 🎯 Objectives
- Analyze customer behavior
- Find popular destinations
- Analyze travel and package types
- Study booking and revenue patterns
- Analyze payment methods and cancellations
- Analyze loyalty members and app usage
- Find relationships between data using correlation

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis
- Customer Analysis
- Destination Analysis
- Travel Type Analysis
- Package Type Analysis
- Transport Mode Analysis
- Booking & Revenue Analysis
- Loyalty & App Usage Analysis
- Correlation Analysis
- Data Visualization

## 📁 Files
- `travel.ipynb` – Complete analysis
- `travelapp_dataset.csv` – Original dataset
- `cleaned_travel_dataset.csv` – Cleaned dataset
- `final_travel_analysis_dataset.csv` – Final dataset
